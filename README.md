# DialektoPH Learning Hub

Create a very simple, clean, minimalist website called DialektoPH.

Use a soft green and white color palette, simple typography, clean layouts, and minimal decorations. Keep everything extremely simple. Avoid complex animations, unnecessary components, and excessive design elements.

Pages and Features

Login – Demo login only. No password or credentials required. Clicking Sign In proceeds to the dashboard.

Dashboard – Show a welcome message, learning progress, and available languages.

Lessons – Provide lessons for:

Tagalog

Cebuano

Ilocano

Hiligaynon

Waray

Quiz – Simple multiple-choice quizzes with scores.

Profile – Display and edit the learner's name and basic information.

Leaderboard – Only accessible after joining a class using a class code.

Navigation

Add a simple navigation bar with:

DialektoPH logo on the top left.

Dashboard

Lessons

Quiz

Leaderboard

Profile

Light/dark mode toggle.

Technical Requirements

Use React, TypeScript, and Tailwind CSS.

Make all buttons and navigation functional.

Use localStorage for demo login and learning progress.

No backend, database, API keys, or real authentication.

Must run locally in WebStorm.

IMPORTANT: Keep the entire project extremely simple. Prioritize functionality over complicated design. Do not add features that were not requested. Avoid unnecessary code and components to minimize development complexity.
